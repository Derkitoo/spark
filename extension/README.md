# Spark Chrome Extension

## Installation locale

1. Dans Supabase, ajouter cette Redirect URL :
   `https://hehgdmclcaphmfcpklggnnpjielmimha.chromiumapp.org/supabase`
2. Ouvrir `chrome://extensions`.
3. Activer le mode développeur.
4. Cliquer sur « Charger l’extension non empaquetée » et choisir le dossier `extension`.
5. Ouvrir l’extension et se connecter avec le même compte Google que Spark.

Le raccourci par défaut est `Ctrl+Shift+Y` (`Command+Shift+Y` sur macOS).
